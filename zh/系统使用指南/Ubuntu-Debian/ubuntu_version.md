# Ubuntu/Debian 固件版本

Firefly 固件提供 `ffgo` 命令用于查看固件信息。向 Firefly 反馈问题时，建议附上 `ffgo version` 的输出。

```bash
ffgo
ffgo update
ffgo version
```

示例输出：

```text
OS:      Ubuntu 18.04.5 LTS
MODEL:   Firefly RK3566-ROC-PC HDMI(Linux)
FIREFLY: v2.04-1-g618089a
DATE:    20210316-1035
KERNEL:  Linux version 4.19.172 ...
```
