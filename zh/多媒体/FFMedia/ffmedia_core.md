# FFMedia 简介

FFMedia 是面向 Linux 多媒体应用的模块化音视频框架，可支持应用软件快速开发 。它重点适配了Rockchip 硬件能力，将芯片相关的复杂的底层处理，根据其功能封装成对应的可复用的功能模块，它将 Camera、文件、网络流、解码、编码、图像处理、推理、显示、录制和推流封装为功能模块，方便用户快速组合开发自己的多媒体应用。

## 核心特点

### 可组合的媒体管线

模块可以单独运行，也可以根据功能需求组合成管线运行，一条管线通常由输入、处理和输出模块组成。每个模块都可以替换、分支和汇聚，同一份数据也可以同时送往多个下游模块。

### 硬件加速

FFMedia 将常用平台能力封装为模块：MPP 用于视频硬件编解码，RGA/GPU 用于图像前处理（包括裁剪、缩放、旋转及合成），DRM用于直接显示，RKNN 用于 NPU 推理等。

### 统一的配置和生命周期

C++、Python 和 `ffmedia` 命令行使用同一套参数模型。模块都遵循统一的配置、连接、初始化、启动和停止流程，开发者可以先用命令行检查模块和参数，再将配置迁移到应用中。

### 共享 Buffer 和扩展能力

媒体数据通过 `MediaBuffer` 在模块之间零拷贝传递。在设备和模块支持时，使用 DMA-BUF 共享底层内存，减少数据跨硬件设备复制。

C++ 应用可以直接组合已有模块，也可以通过 `ModuleAppSource`、`ModuleAppProcessor` 或继承 `ModuleMedia` 接入自己的数据源和处理逻辑。
