# RTLinux

## 前言

本文介绍 Linux 内核实时性补丁的基本使用方法，帮助开发者快速了解并使用实时系统。

---

## 简介

**RT-Linux** 并非指某一个单一的操作系统，而是**一系列使 Linux 内核获得实时能力的方案集合**。其共同目标是在保留 Linux 通用生态（驱动、库、开发工具）的同时，为任务执行注入时间确定性——即保证高优先级任务在规定的时间边界内得到响应。在这一目标下，主流路径分为两支：**PREEMPT_RT** 选择改造 Linux 内核本身，使其“可抢占化”；**Xenomai** 则选择在 Linux 之外另设一个更高优先级的实时核心。两者在实时性强度、生态兼容性与开发复杂度上形成了不同的取舍。
